How this works: This reads text out of your screenshot using OCR running entirely in your browser (nothing is uploaded anywhere). It does its best to guess the player/team, market, line, and odds, but bet-slip screenshots vary a lot — anything it can't read confidently is left blank for you to fill in. You always get a review screen before anything is saved; nothing is added automatically. The OCR library (~2–10 MB) downloads from a CDN the first time you use this tab, so it needs an internet connection once.

Appearance & preferences

Theme: Court Side (charcoal surfaces, basketball orange, warm cream text) — the default and only theme available right now.

Win/loss/live/pending/push-void always use the same colors throughout the app: green for a confirmed win, red for a confirmed loss, blue for open/live, amber for pending or needs-review, and neutral gray for a push or void — never orange/amber for a confirmed loss.

App information & data integrity

Props saved only in this browser, on this computer — not synced anywhere else. Use "Export backup" to save a copy you can restore later or move to another computer.
